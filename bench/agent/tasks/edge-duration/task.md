`parseDuration(text)` in `src/duration.mjs` turns a duration such as `1h30m` into seconds, but it only understands hours followed by minutes. Make it accept every combination of the units `h` (hours), `m` (minutes) and `s` (seconds): each unit at most once, in the order h, m, s, at least one unit, each with a non-negative integer. So `2h` is 7200, `45s` is 45, `1h5s` is 3605, `1h30m` is 5400, `3m15s` is 195, `1h2m3s` is 3723 and `0s` is 0. Anything else throws an Error: an empty string, a unit out of order (`1m1h`), a repeated unit (`1h1h`), a unit with no number (`h`), an unknown unit (`5x`), or a number with no unit (`90`). Keep the existing tests passing.
