`parseCsv(text)` in `src/csv.mjs` turns CSV text into an array of rows, each an array of string fields, but it breaks on anything beyond a plain quoted field. Make it follow these rules. Rows end at `\n` or `\r\n`; a line break at the very end of the text ends the last row and starts no new one, and empty text gives `[]`. Fields are split on `,` and empty fields are kept; an empty line in the middle is a row with one empty field. An unquoted field is taken as it is, with no trimming. A field that starts with `"` is quoted: inside it `""` is one `"`, and commas, `\n` and `\r\n` are literal text. An unterminated quote throws an Error, and so does a closing quote followed by anything other than `,`, a line break or the end of the text. Keep the existing tests passing.
